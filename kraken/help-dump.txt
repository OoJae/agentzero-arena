Spot paper trading (simulated, no real money). For futures paper trading, use `kraken futures paper`

Commands:
  init        Initialize paper trading account
  reset       Reset paper account. Optionally override balance, currency, or fee rate
  balance     Show paper balances
  buy         Place a paper buy order
  sell        Place a paper sell order
  orders      Show open paper limit orders
  cancel      Cancel a paper limit order
  cancel-all  Cancel all paper limit orders
  history     Show paper trade history
  status      Show paper account summary with P&L
  help        Print this message or the help of the given subcommand(s)

  -o, --output <OUTPUT>
          Output format: table (default) or json [possible values: table, json]
  -v, --verbose
          Show request/response details on stderr
      --api-url <API_URL>
          Override Spot API base URL
      --futures-url <FUTURES_URL>
          Override Futures API base URL
      --api-key <API_KEY>
          API key override (takes precedence over env/config)
      --api-secret <API_SECRET>
          API secret override (prefer --api-secret-stdin for security)
      --api-secret-stdin
          Read API secret from stdin (mutually exclusive with --api-secret and --api-secret-file)
      --api-secret-file <API_SECRET_FILE>
          Path to file containing API secret (mutually exclusive with --api-secret and --api-secret-stdin)
      --otp <OTP>
          OTP (two-factor authentication code)

  -h, --help
          Print help
